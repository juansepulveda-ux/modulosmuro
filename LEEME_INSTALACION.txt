COLORES DE MÓDULOS EN INSCRIPCIONES

Instala este paquete DESPUÉS de actualizacion_aviso_pago_clientes.zip, si todavía no has subido aquella actualización. Este ZIP solo incluye los seis archivos del cambio de colores, no reemplaza el repositorio completo.

1. Descomprime el ZIP.
2. En la raíz del repositorio modulosmuro, usa Add file / Upload files.
3. Sube configuracion.html, inscripciones.html y las carpetas assets y lib conservando las rutas. Reemplaza solo los archivos incluidos; no borres las carpetas existentes ni los demás archivos.
4. Confirma los cambios y espera que Vercel termine el despliegue.
5. Recarga Configuración e Inscripciones. Si sigues viendo la versión anterior, usa Ctrl+F5.

USO
Entra como administrador a Configuración y busca “Colores de módulos en Inscripciones”.
Elige el color de Muro y el de Airtrail + Tirolesa y pulsa Guardar configuración.
En Inscripciones, pulsa Actualizar para aplicar los colores nuevos. También se aplican durante la actualización automática habitual.
Los valores iniciales son lila para Muro y celeste para Airtrail + Tirolesa.
El fondo completo de cada caja cambia de color y el texto principal pasa automáticamente a blanco o negro para mantener contraste. El tipo de módulo también aparece con un título más grande. Los avisos y botones conservan sus estilos propios.
Airtrail y Tirolesa siguen compartiendo módulo. Estos colores solo se aplican a las cajas de Inscripciones.

DATOS
No incluye data/, no elimina módulos, dotación, clientes, inscripciones ni declaraciones y no requiere migración. Conserva la protección de reservas y los ajustes existentes. No cambia credenciales, variables de entorno ni funciones de Vercel.
Guardar colores modifica únicamente la configuración mediante el mecanismo existente.

VALIDACIÓN
